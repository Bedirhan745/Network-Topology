# Network-Topology

  ## Proje Hakkında

  Bu çalışma, ağ topolojileri üzerinde yol bulma problemini ele almaktadır.
  Dijkstra, Q-learning ve Ant Colony Optimization (ACO) algoritmaları
  kullanılarak kaynak–hedef arasındaki en uygun yol hesaplanmıştır.
  Algoritmalar gecikme ve güvenilirlik metriklerine göre karşılaştırılmıştır.


  ## Random Seed

  - Q-learning: seed = 42
  - ACO (MMAS): seed = 42


  ## Çalıştırma Adımları

  1. Python 3.9 veya üzeri yüklü olmalıdır.

  2. Proje dosyalarını indirin veya Git deposunu klonlayın:

```bash
git clone https://github.com/Bedirhan745/Network-Topology
cd Network-Topology


  3. Gerekli kütüphaneleri yükleyin:

      pip install -r requirements.txt

  4. Ana program dosyasını çalıştırınız:

       python main.py
